# Job Aggregator System - End-to-End Data Pipeline (ETL)

This project is an end-to-end job aggregation pipeline that collects job data from multiple sources, processes it, and stores it in a structured format.

## 🚀 Features
- Scrapes job data from multiple job portals
- Cleans & transforms raw job listings
- Loads processed data into storage
- Fully automated ETL pipeline

## 🛠️ Tech Stack
- Python
- BeautifulSoup / Selenium (web scraping)
- Pandas
- ETL pipeline automation
